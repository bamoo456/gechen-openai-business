BetaFlagship

TripPocket

An agent-ready travel knowledge layer.

Travelers save tips, places and sources once. Any authorized AI agent, such as Claude or a custom agent, can then read, search and add to that knowledge, with provenance on every item.

  • Remote MCP server and REST/OpenAPI over the same domain model
  • Scoped Agent Access Tokens: users see and revoke what each agent can do
  • Pockets, Places, Sources and Knowledge Items with full source attribution

ACP Gateway

Run coding agents on your own machine. Use them from anywhere.

ACP Gateway exposes local coding agents such as Claude Code over a private network, with an authenticated web console and a native iOS app. Code, credentials and agent state never leave the host.

  • Live diffs, plans and touched files next to the conversation
  • Permission requests answered from web or phone, with notifications that link back to the thread
  • Branch a conversation, or hand it off from one agent to another
  • Native SwiftUI console with Keychain-stored credentials and Face ID lock

ParkNearby

A map-first iOS app for drivers in Taipei and Taoyuan: nearby parking, current rates and real-time vacancy from official open data, with the age of every data point shown.

Native SwiftUI app plus a small API service for live roadside availability. Our test bed for shipping consumer mobile products end to end.

Built on Claude

Claude is our primary model, in the product and in how we build it.

We design for Claude’s strengths: long-context reasoning, reliable tool use and agentic coding.

In TripPocket

MCP-native knowledge

Claude connects to TripPocket over MCP to search, cite and save travel knowledge on the user’s behalf, under scoped and revocable tokens.

In ACP Gateway

Claude Code, anywhere

The gateway runs Claude Code through the Agent Client Protocol and supports session forking, model and thinking controls, and human approval of tool calls.

How we work

Agentic engineering

Claude Code is our main engineering workflow. Agents open issues and pull requests, run CI and go through review before anything ships.
