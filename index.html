BetaFlagship

TripPocket

An agent-ready travel knowledge layer.

Travelers save tips, places and sources once. Any authorized AI agent — Claude, or a custom agent — can then read, search and add to that knowledge, with provenance on every item.

Open TripPocket (opens in a new tab)

  • Two interfaces, one domain model

    A remote MCP server and a REST/OpenAPI surface sit over the same model, so agents and apps see the same knowledge.

  • Scoped Agent Access Tokens

    Agents connect with scoped Agent Access Tokens that users can see, and revoke, at any time.

  • Provenance on every item

    Pockets, Places, Sources and Knowledge Items, with source attribution carried on every item.

Open source, MITWeb + iOS

ACP Gateway

Run coding agents on your own machine. Use them from anywhere.

Coding agents such as Claude Code run on your machine, and you reach them through an authenticated web console and a native iOS app. Code, credentials and agent state stay on the host.

ACP Gateway on GitHub (opens in a new tab)

  • See the work, not just the chat

    Live diffs, plans and touched files sit beside the conversation.

  • Approve from web or phone

    Permission requests reach you as notifications that deep-link back to the thread.

  • Branch or hand off

    Branch a conversation, or hand it off from one agent to another.

  • A native iOS console

    Built in SwiftUI, with credentials in Keychain and an optional Face ID lock.

ParkNearby

Map-first parking for drivers in Taipei and Taoyuan.

Nearby parking, current rates and real-time vacancy from official open data. The age of every data point is shown, so drivers know how fresh it is.

  • Native SwiftUI

Claude is in the product — and in how we build it.

Claude is the agent we build with and build for: inside TripPocket and ACP Gateway, and across our engineering workflow.

  • In TripPocket

    Claude, connected over MCP.

    Claude connects to TripPocket over MCP to search, cite and save travel knowledge on the user’s behalf, under scoped, revocable tokens.

  • In ACP Gateway

    Claude Code, over the Agent Client Protocol.

    ACP Gateway runs Claude Code via ACP, with session forking, model and thinking controls, and human approval of tool calls.

  • How we build

    Agentic engineering, reviewed.

    Claude Code is our main engineering workflow. Agents open issues and pull requests, run CI, and go through review before anything ships.

    issue → PR → CI → review → ship
